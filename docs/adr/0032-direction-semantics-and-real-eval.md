# ADR-0032 · 方向语义修正 + 真实标注评测 + inquiry 决策纳入否决指令

- 状态：accepted
- 日期：2026-11-19
- 关联：ADR-0029/0030/0031；C4/C6

## 背景（review 发现）
1. **语义 bug**：「删除/去掉/取消 X」被当成"排除 X"（hard-exclude），导致候选里只要提到 X——**包括正确的"删除 X"方案**——都被排除，甚至整盘 `undecidable`。
2. **决策谱系漏否决指令**：`deriveDecisions` 只收 goal/changed/拍板，`#68「不要多数据库抽象」`不在其中 → inquiry 决策段空，靠"否决集"兜底。
3. **真实评测缺失**：此前只有模板合成集（自洽），缺**真实人工标注**的真实准确率。

## 决策
1. 信号拆分：**「不要/别/不用」= 排除该选项**（hard-exclude）；**「删除/去掉/取消」= 要执行的移除动作**（进 `preferred`，**不**入 excluded）。
2. inquiry 决策谱系：额外纳入"否决/改/替换/定稿/确认/直接发"型**用户指令**（标 `〔user·指令〕`），补 `deriveDecisions` 的覆盖缺口；证据句柄**排除脚手架原子**。
3. **真实标注评测**：`tools/bench-direction.ts --labeled <jsonl>`，对**仓外**人工标注的真实语料集（`_materials/direction-labeled/*.jsonl`，不入党）算真实准确率；失败项逐一打印 utt/期望/实际/句柄。
4. ADR-0031 的规模化合成基准（120 例）+ 性能门继续保留在 verify。

## 后果
- ＋ 修正"删除≠排除"（真实标注 77.8%→**100%** on 9 例高信号集）；决策谱系含否决指令；有真实标注评测入口。
- － 真实标注集仍**小且由 agent 人工标注**（非独立第三方、非大样本），**真实泛化率未获统计置信**；需扩样与多人复核。
- 所有输出仍只排序/组装证据，不裁决、不造假（C1–C7）。
