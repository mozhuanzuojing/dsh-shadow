# ADR-0030 · 对 AI 的多维背景问询（`inquiry` 透镜）→ 0 偏移方向

- 状态：accepted
- 日期：2026-11-19
- 关联：ADR-0029（词法方向）、ADR-0024/0026（面/升降维）、C1–C7

## 背景
`direction`（ADR-0029）是**词法近似**，存在偏移（同义/整体否决等）。若把 `.shadow` 的**多维背景**（决策谱系、任务/面、线点、口味、灵魂、证据句柄、盲区）连同「方向假设」一起交给 AI，AI 可据此推出**更接近 0 偏移的真实意图方向**，并校准/纠偏词法估计。

## 决策
新增 `src/domain/inquiry.ts`（纯模板，不 LLM 编造）与 `read_shadow({inquiry:true, topic?, candidates?})`：
- **组装多维背景**：方向假设（词法初估·非采纳）＋ 决策谱系（为什么）＋ 任务/面（来龙去脉）＋ taste 口味 ＋ soul 视角 ＋ **证据句柄**（可回点）＋ 候选偏移（若给）。
- **结构化提问**：请 AI 给出①一句话「0 偏移方向」；②3 条依据（**贴证据句柄**）；③候选偏移最小/应否决与纠偏；④仍不确定、需用户裁决处。
- 明示纪律：只依据背景与证据、勿编造、区分事实/推断/不确定；**词法方向是可被证据推翻的假设**。

## 关键约束（守 C1–C7）
- 插件**只组装证据与问题**，不产出真假/采纳结论、不改写记忆、不替用户裁决。
- 证据句柄必须真实可回点；盲区（failing）显式：仅当前工作区可见，跨工作区/用户态受沙箱限制。

## 后果
- ＋ 把"数学近似偏移"接到"AI 依多维背景做 0 偏移推理"，二者互补：词法快筛/门控，AI 精读/纠偏。
- － AI 侧回答不在插件内（不落事实）；问询可能被记忆中的旧噪声干扰（需证据门 + 用户裁决）。
