# ADR-0026: 点→线→面→观察意识——升降维双锚记忆

- 状态：accepted（2026-11-17；用户「A+B」= 双锚：0维事实锚 + n维意识锚，方向已批；实现分阶段）
- 日期：2026-11-17
- 关联：ADR-0024（Observer 投影核心）、ADR-0025（投影提为默认）、CONTRACT C1–C7、ADR-0002（storage，部分 supersede）
- 定位：回答「记忆的维度和轴是什么」——不是四层套娃，而是**同一存在的不同维度**；**升维**是点→线→面→意识的正向积分，**降维/投影**是反向读取。

## Context

- 「一句话一个文件」把 **0 维的点**当成落盘单位，记忆永远停在最低维——散、升不上去。
- 只读原型（真实 848 点）实证：按现有轴升维 → `848 点 → 57 线 → 1 面 → 1 意识`。**第一维（线）连得出结构，但第二维（面）塌成 1**：因为点的坐标太贫（`entry` 全回退成项目名 `dsh1`、`role=default`、无 `soul`、无 `task/topic` 轴）。⇒ **没有轴，就没有升维；升维塌成一维。**
- 用户本体（2026-11-17）：话=点；点是观察的**面**上的**线**上的一个点；让点回到线、线回到面、面回到观察意识。**是升维，不是分层。**

## Decision

**双锚（A+B，缺一不可）**

- **A · 0维事实锚**：点（一条话/一次观察/一个动作）是**不可变、可核查**的事实单位；证据句柄 MUST 可解析。C1 不破。
- **B · n维意识锚**：观察者整体（`soul` / Observer 视角）是一等锚——面只在「谁在看」里成立；意识可解释、可降维回事实。

**四维 + 升降维**

```
观察意识 nD   ← 面在其中被看见（soul/Observer 视角；可分全局/会话多层）
   ↑ 降维投影（读取：意识→面→线→点，必可回到点句柄）
  面 2D        ← 多条线沿第二轴织成（任务/主题/观察者/日）
   ↑
  线 1D        ← 点沿第一轴连成（时间 × 入口/意图）
   ↑ 升维积分
  点 0D        ← 事实（不可变）
```

**三个轴 MUST 显式**（否则升维塌缩，见 Context 实证）

1. **线轴**：时间 × 入口/意图（现 Episode 的切法，升为源级容器）。
2. **面轴**：任务 / 主题 / 观察者 / **会话** / 日（至少一个能让面 > 1 的轴）。当前「会话」轴可用（16 面）；**「任务」面已实现**——`deriveFaces(atoms,"task")` 对线做**确定性词法聚类**（无 LLM），真实语料 57 线 → **13 任务面**，`read_shadow({dim:"task"})` 可读；`dim:"face"` 仍会话轴。任务面是词法近似（同义/翻译可能分错簇）。
3. **意识轴**：观察者视角（`soul`）；可分「全局 1 + 每会话/每 agent 多视角」。

**落盘（回答「去掉一句话一个文件」）**

- **落盘单位从「点」升到「线」**：一个文件 = 一条线（append-only 流），线内按序存点；**每个点带稳定子句柄** `lineRel#<seq>`——形散而证据不散。
- 面 / 意识是**升维派生**（可重建，删了不丢事实）；点是**降维视图**（从线切出）。
- 点（atom）仍是事实单位与证据来源，但**不再「一句话一文件」独立暴露为唯一源容器**；旧 `atoms/` 继续可读（兼容）。

**不变量（双锚的接缝）**

- **守恒**：任一次升维后，Σ(线内点) == 原点集合；MUST 可断言。
- **可回溯**：面/线的每个元素 MUST 能降维到具体点句柄；无句柄的「面/意识」按 confabulation 处理（C7）。
- **意识不越权**：意识/面只读、只派生，不改点、不造事实（C1/C2/C7 续）。

## Consequences

- 正：记忆从「点堆」变成「可升维的整体」，能回答「这件事的面是什么、谁在看、盲区在哪」；证据仍可核（A），意识仍可解释（B）。
- 负：storage 模型变（点→线容器），迁移 / parity / 审计要重做；线内点句柄需稳定；轴的选取要定（面轴不明就塌回 1）。
- 边界：原型已证「齿轮+守恒」成立；但真实语料当前坐标贫，面/意识会退化——**先补点坐标与面轴**才谈收益。

## Non-goals

- 不引向量库；不丢证据（A 必守）；不做「无轴的伪升维」；不在本条一次搬完 v1 的 231 invariant 研究面。

## Phase B 设计（线容器——「去掉一句话一个文件」的落地）

- **文件单位 = 线**：`.shadow/lines/<YYYY-MM-DD>--<session>--<entry>.md`；一条线一个文件，线内**按序**存点。
- **点在线内带句柄**：`- [点#<seq> <time> <kind>] <text> {{rel=<atomRel>}}`——形散而证据不散（A 锚保住，`rel` 仍可解析）。
- **闭合规则**：同一 `session + entry` 且与上一点间隔 ≤ `compact.gapMinutes`（默认 60）→ **续接**；否则**另起一条线**（新文件）。
- **写侧**：`capture.flush` 由「写一个 atom 文件」改为「把本回合的点 append 到当前线（无则新建）」；线**只追加**，不改写旧点（点不可变）。
- **读侧**：读路径按「先线后面」——`loadLines` 解析线文件为点集（等价现 atoms 集合，守恒），面/意识由 `domain/dimensions` 升维。
- **兼容（dual）**：旧 `.shadow/atoms/` 继续可读；新模式写 `.shadow/lines/`。切换用配置/版本灰度，旧数据不迁移、不删。
- **不变量**：Σ线内点 == 原点集合；每点归且仅归一条线（`session+entry+gap`）；点句柄必可解析。
- **本阶段先落原语**：`domain/lines.ts`（线头 / 追加 / 解析 / 闭合 / 线 id），已单测；**接采集与读路径在后续刀**，不一次动骨头。

## 分阶段（先哲学后结构，每阶段过 `npm run verify`）

- **A（本条 + 原型）**：ADR-0026 + 只读升降维原型（细轴），验证 面>1、意识分层、守恒。
- **B（线容器）**：写侧落盘从点升到线（`shadow/lines/`），点带 `lineRel#seq`；旧 `atoms/` 继续可读（dual）。
- **C（升维派生 + 降维读）**：面/意识派生；`read_shadow` 支持按维读（点/线/面/意识）并可降维钻取。
- **D（迁移/parity/收口）**：迁移、oracle 重录、文档。
