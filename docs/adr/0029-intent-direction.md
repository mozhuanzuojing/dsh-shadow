# ADR-0029 · 隐式偏好 → 最小偏移方向（`direction` 透镜）

- 状态：accepted
- 日期：2026-11-19
- 关联：C2/C4/C7；ADR-0024（Observer 投影）、ADR-0026（升降维）

## 背景
用户**从不显式说"采纳/否决"**，而是靠继续阐述表达意图（"都不要"、"用Y代替X"、"只要…去掉…"、"我的意思是…"），且 agent 常**理解偏**。需要把多轮用户话语估成"意图方向"，让候选方向中"偏移最小"者浮出。

## 决策
新增 `src/domain/intent.ts`（纯函数、零依赖、确定性）：
1. **规则信号分类**：`negateAll / replace(用Y代替X) / narrow(不要X/去掉X) / sync / overturn / cite / softPrefer / restate`，产出 {否决集, 替换对, 偏好}。
2. **方向估计**：用户话语分词（ASCII 词 + 中文 2-gram）→ 稀疏 TF-IDF → L2；EMA 质心 `m←(1−α)m+αx`，遇纠正/否决**临时上调 α** 再回落；冷启动按轮次等权。方向关键词 = 质心 top 词。
3. **候选排序**：命中否决/被替换项 → **硬排除**；其余按 `偏移 = 1 − cos(质心, 候选)` 升序。
接入 `read_shadow({direction:true, topic?, candidates?})`。

## 关键约束（来自 critical-analyst 压测）
- **纯余弦会反向**：「都不要」是对候选集合的**整体否决算子**（无方向），高频词候选反而得分最高 → 必须 **hybrid：规则先行定极性/作用域/指向，余弦只在幸存候选内排序**；两者不可互替。
- 分数**仅用于排序**，外显必须标「**方向假设 · 非采纳**」；不判真假、不改写记忆、不替用户裁决（守 C1–C7）。
- **只对用户 turn 建模**（剥离 agent 脚手架/假设语）；IDF 抑高频。
- **fail-closed**：样本不足 / 整体否决且无替代 / 候选全被否 → 返「不可判」，不猜最小分。

## 后果
- ＋ 可解释（关键词/信号/偏移）、可测（6+ 情境回归 `test/unit/intent.test.ts`、读侧 `read-direction.test.ts`）、零依赖。
- － 词法近似不覆盖同义/语义（待验证）；规则词表需随语料扩充；α/阈值需标定（现为常量）。

## 备选（调研，未采用）
IRL/偏好学习（需成对标注）、在线凸优化（步长敏感）、ADWIN 漂移检测（阈值难调）、Procrustes（重）。取最简 hybrid。
