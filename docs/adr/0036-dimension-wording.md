# ADR-0036 · 维度口径澄清：四层投影 + 时间轴；意识=全局单层聚合

- 状态：accepted
- 日期：2026-11-19
- 关联：ADR-0026（点→线→面→观察意识）、ADR-0028（scope 轴）；本 ADR 只澄清**口径**，不改实现，也不改 ADR-0026 正文。

## 背景（团队验收发现）
对 dsh-shadow 的"维度"表述做过验收，发现**过度宣称**：
- API 只有 `dim = line / face / task / consciousness`（`tools.ts`）——**没有 `dim:time`、没有 `dim:point`**。
- **时间**只是每点 `when()` + `date/time` 排序 + gap 切分，是**坐标轴**，不是独立投影维。
- **面**里 `task`（词法聚类）与 `project`（soul lens 取景+盲区）是**实质取景**；而 `session / day` 多为**单字段 group-by（聚合换名）**。
- **意识**（`dim:"consciousness"`）当前是**全局单层聚合**：面/点计数 + entry 频次 + soulId 标签 + **固定盲区文案**；**多视角、盲区来自"被排除点"尚未落地**。
- 另有实现隐患：`dim:"line"`（按线文件/atom@date）与 `deriveFaces().lines`（按 session+entry+gap Episode）是**两套"线"口径**，统计/守恒断言需标明用哪一路。

## 决定（对外与文档口径）
1. 统一表述为 **「点 → 线 → 面 → 观察意识 四层投影 + 时间坐标轴」**；**不再称"五维（点/线/面/时间/意识）"**。
2. 提到**意识**时必须注明：**全局单层聚合；多视角与"盲区来自被排除点"待落地**，不得称"n 维多视角观察意识"。
3. 提到**面**时注明：`task`/`project` 为实质取景，`session`/`day` 为聚合。
4. 提到**线**时，`dim:line` 与 `deriveFaces` 的线**两口径并存**，统计断言须标明来源。

## 后果
- 文档/描述与实现一致，避免"宣传≠实际"；`README`、`STATUS` 已按此修正。
- "时间维（`dim:time`/as-of）"与"lens 化多视角意识"列为**未来增强**，不在本 ADR 承诺。代码层注释/工具描述中的"n 维"字样在后续代码改动中一并收敛（P1）。
