# ADR-0034 · 术语澄清 + 真实标注集边界

- 状态：accepted
- 日期：2026-11-19
- 关联：ADR-0030（inquiry）、ADR-0032（真实评测）、ADR-0033

## 澄清（不改 ADR-0030 正文，用本 ADR supersede 其措辞）
- **`inquiry` 不是"插件推出 0 偏移方向"**；它是**把多维背景组装成上下文+问题，供调用方 AI 依证据纠偏**，目标是逼近「0 偏移方向」——**目标表述，不保证达成**；插件不产出结论、不裁决（C4）。
- `read_shadow({direction})` 的候选排序仍是**词法弱先验**（可能误导，已标注）。

## 真实标注集边界（诚实）
- `tools/bench-direction.ts --labeled` 用的真实语料集在 `_materials/direction-labeled/`（**仓外、不提交**）。
- 现真实语料（清空历史后）仅 **8 条指令型用户话**，故真实标注集 **n 很小**、由 **agent 人工标注**、含少量负对照；**无统计置信、非独立第三方**，只能作"回归/冒烟"，不能当泛化率。
- 更大规模需**继续积累真实语料 + 多人复核**后再评。

## 后果
- 文档/工具描述把"推出 0 偏移"改为"**供 AI 纠偏（目标）**"；避免过度宣称。
- 合成基准（模板，120 例）仅证"规则自洽回归"；真实准确率仍属"未获统计置信"。
