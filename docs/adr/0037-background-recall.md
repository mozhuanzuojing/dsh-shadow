# ADR-0037 · 频率相近的「大背景」召回（`read_shadow({background})`）

- 状态：accepted（能力实现 + 基准达标；是否发版见 CHANGELOG/提交记录）
- 日期：2026-11-19
- 关联：ADR-0024（证据/投影分层）、ADR-0026（点→线→面→观察意识）、ADR-0031（Forget≠Delete）、ADR-0036（维度口径）

## 背景（要回答的问题）
"用户未来的一段话，能不能找到和他**频率相近的大背景**？"——即给定**换措辞/改频率**的未来句，能否召回**这件事的大背景**（相关线、决策/否决、口味、证据句柄），而不只是零散词条。
实测旧检索有三个坑：①只字面重叠（BM25/2-gram，非语义）；②`面/任务`按固定轴、不随 query 组装；③**我方任务 prompt / goal / 元文本**占榜，把真决策挤下去。

## 决定
新增只读透镜 **`read_shadow({ background: true, topic })`**，返回"未来句 → 大背景包"：
1. **去噪 + 去重**（`cleanRetrievalAtoms`）：剔除任务 prompt/脚手架/元讨论，按 body 去重；应用于 topic/query/投影/任务/决策视图。
2. **按用户原话打分**（`domain/background.ts buildBackground`）：只用「用户：」行匹配，避免 goal/analysis 元文本压过真决策。
3. **近似召回**：`searchTerms`(BM25 中文 2-gram) + **罕见汉字 IDF 字符级**（≥4 字，补远同义如"吸气停一秒"↔"吸6/停1/呼4"）；匹配前**去疑问/停用词 + 少量同义**(偏好≈喜欢) 以降假阳。
4. **组装大背景**：命中点→**按线归并**（时间范围/样例）+ **相关决策/否决**（滤 ack/元文本）+ **相关信息（事实/材料/约束）**（材料引用 + 背景型原话：描述现状/不一致/来源）+ **口味** + **证据句柄**（可回点）。背景**不止决策**——信息与决策并列。
5. **关系网（ego-net）**：背景不是"一句话"，是**点之间的网**。`domain/graph.ts` 从 atom 字段**确定性派生边**——结构边（`same-line` 同线相邻 / `same-entry` 同入口 / `material` 共享材料 / `correction` 纠正指向）+ **语义边**（`semantic`：共享罕见 2-gram 关键词，df 2–3，每节点 ≤3，防 hub）+ **因果边**（`causal`：决策 ↔ 其材料/理由出处，每节点 ≤3）；再以命中点为种子 **沿边扩散 2 跳**（节点上限 30），输出「关系网（节点/边/跳数）」——把**未被字面命中、但通过关系相连**的上下文带进来。
6. **补采集（写侧）**：`capture` 现记录 ①决策 `reason`（因为/由于…）；②决策/信息里显式提到的**材料路径**；③**信息(`info`) 事件**（背景型用户原话＝事实/材料/约束）——写入 atom 的 `> 决策理由 / > 背景/材料 / > 信息`，供读侧"决策+信息+因果网"取用。

## 验收（可复现）
`node tools/bench-recall.ts`（真实 `.shadow`，只读；正例=换措辞未来句→期望决策，负例=跨域无关句）：
- 验收线：**关键词/同义型召回 ≥90%**、**假阳 ≤10%**（n≥20）。
- 实测（n=16 正 / 15 负）：**召回 16/16（100%）、MRR 0.97、假阳 0/15（0%）**；**网含同线邻居 16/16、平均网节点 14.6**。

## 边界（诚实）
- 仍是**词面 + 字符 + 小同义表**近似，**非真语义**；对**全新同义/跨域抽象**可能漏——"任意一段话"未证。
- **可选真语义重排**：`SHADOW_SEMANTIC=1` 时用现有 embedder 链（默认 `local`，可 `SHADOW_EMBED_PROVIDER`）对种子做余弦重排；**默认关**（保持零依赖默认路径），失败显式提示并回退词法。
- 评测集为**开发期自建（非独立标注/非统计显著）**；阈值与同义表为**经验标定**，需更大标注集校准。
- **真语义(embedding)** 会**破"零运行时依赖"**（引模型/体积），列为**opt-in 未来**，需授权。

## 后果
- 提供"跨会话记忆可按未来句取大背景（关键词/同义层）"的可用能力，且**证据可回点、降级可见**（无匹配显式声明）。
- 不改变存储层：仍以 atom/line 为证据源，background 为**派生只读视图**（C1/C4 不破）。
- **边是推断**（同线/同入口/材料/纠正/共享关键词/决策↔材料），带 derivation 规则，可能连错——必须可核查/可撤销；hub 限扩（节点 ≤30，语义/因果每节点 ≤3）。
- **语义边是"词面共现"不是真语义**；**因果边依赖"决策↔材料/理由"被记录**——而当前 capture 对 reason/material 记录稀疏，故真实语料里因果边很少（实测网内 `same-line×78/66`、`semantic×4/13`、`causal` 罕见）。要让"因果网"长出来，需先**补采集决策理由/材料引用**（后续）。
- **信息（事实/材料）同样稀疏**：materials 字段多数为空、背景型原话也未被稳定分类；当前"相关信息"段在真实语料里**覆盖有限**，补采集后才能让"背景=决策+信息"都饱满。
