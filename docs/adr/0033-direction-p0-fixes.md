# ADR-0033 · 方向/问询 P0 修正（不可判不显偏移 · "别"误抽 · 泛词误杀）

- 状态：accepted
- 日期：2026-11-19
- 关联：ADR-0029/0031/0032；C4（不替用户裁决）

## 背景（独立评审 critical-analyst 指出）
1. **fail-closed 漏**：`direction` 在 `undecidable` 时仍逐条打印"偏移 x.xx"（`route.ts` 候选段）——与"不可判禁止猜最小分"矛盾。
2. **「别」误抽**：`别` 作为否决不区分 `区别/特别/别的/差异`，产生噪声排除词。
3. **泛词误杀**：子串硬排除下，`不要文件` 会排除一切含"文件"的候选（过度）。

## 决策
1. `direction` 不可判时**只给原因，不输出任何数字偏移**；测试断言 `!/· 偏移 \d/`。
2. `别` 加边界：`(?<![区特级分类])别(?!的|差|异)`，保留 `不要/不用/别用/别再`。
3. 新增 `GENERIC` 泛词集（文件/方案/功能/…），**不作为排除项**（不进 excluded），防误杀。

## 后果
- ＋ fail-closed 名实相符；减少误抽/误杀；回归测试覆盖。verify 82/82。
- 遗留（P1，非阻断）：真实标注集仍小（n=9，agent 自标）需扩样/复核；句柄可按"每条结论贴点"加强（C2）；文档把"推出 0 偏移"表述为"**供 AI 纠偏的多维背景**"更准确。
