# ADR-0111: 参考资料面的「清单 / 内容」分层 —— 状态标注由**复核**产生，不由叙述推断

- 状态：Accepted（`v1.22.0`）
- 触发：用户 2026-10-07 指令「参考资料要把**清单**和**内容**拆分开」
- 依据：`adr/0078`（材料台账**由磁盘枚举生成、不由手写清单生成**）· `adr/0085` §8.7/§8.8
  （**能推出来的字段不要手写**；事故经过）· `adr/0089` §1（三份清单对不上，「不是谁错，是四个不同的集合」）·
  `adr/0049`（**缺件不静默**）· `AGENTS.md` 的「每份文档 owned by 什么」表与
  「**要么写进清单、要么配一道门**」· `tools/materials-root.lib.ts` 的文件头（本轮实测）。

## Context

`references.md`（1413 行 / 151,550 B）与 `MATERIALS.md`（418 行）把**三种生命周期不同**的东西装在一起：

| 态 | 样态 | 生命周期 | 谁该维护 |
|---|---|---|---|
| ① **派生清单** | 裸 URL 表 · 口径×条数表 · 覆盖率台账 · 版本许可快照 | **会腐烂，必须能重算** | 生成器 |
| ② **源·核实记录** | 逐份「性质 / 读数 / 判定 / 未核」 | **只追加，是史料** | 人 |
| ③ 导航与口径 | 顶部说明 · 关联度粗分 · 指针 | 半派生 | 人 |

**本轮实测到的后果**（不是「不整洁」，是「已经错了」）：

1. **清单口径五处登记、四个集合**，且**只有 2 处今天可复核**：输入清单 21（可数）· 外仓笔记目录 19（目录已不存在）·
   磁盘快照 22→24（根 `D:`/`G:` 均不存在）· 名册 8 · 生成器输出 24。
2. **两个工具的枚举根都写死** `D:\project\dsh1\vendor\_src`，而本机 **`D:` 整盘已不存在**（实测 `Test-Path D:\` = False）：
   - `tools/materials-ledger.ts` → 每次运行 **exit 2**；`tools/materials-freshness.ts` 同款；
   - 两者**都不在 `verify` 里** ⇒ **没有任何门会发现**；
   - 而 `MATERIALS.md` §1.1 长期以「**当前态 · 由生成器输出、不要手写**」的口吻摆着那份**根已死**的 24 行表。
3. **生成器自己手写派生计数**：实跑 4 个目录，尾部仍打印「✔ **24/24** 都有 `.git`」——违反 `adr/0085` §8.7 的判据。
4. 🔴 **状态标注反转（本轮最值钱的一条）**：`MATERIALS.md` §1 的 8 行名册被注为「**换盘前** · 枚举根已不存在 ·
   8 项里 5 项已无本体 · **不可复核**」，而 2026-10-07 实测 **8/8 全在**于根 `G:\project\dsh1` 下、
   **HEAD 逐项命中**（`cd5ef81481` · `aa5d068` · `592c0fe` · `82e63c9` · `271834d5` · `a160e776` · `b68eeac` · 本仓 `800d2b6`）。
   ⇒ **把对的判成死的、把死的标成当前态**，并且这个错**沿引用链被二次固化**（`references.md` §14 复述为「不可复核」）。
   **审计轮自己也曾照抄这条判词** —— 这就是本条要立成判据的原因。

## Decision

**D1（分层）**：`MATERIALS.md` = **清单面（派生）**；`references.md` = **内容面（源）**。两侧文件头各写**归属声明**，
并声明「**能由磁盘枚举推出来的数不写在内容面**」（写了必漂）。

**D2（迁移，且刻意不破锚）**：`references.md` 的 `## 完整清单`（21 条输入 URL）与 `### 14. 材料面清单`
整体迁入 `MATERIALS.md` **§1.2 / §1.3**；**原处标题原样保留、只留转发占位**。
⇒ 既有引用（`references.md §完整清单` / `§14`，含 `adr/0089` 的 5 处）**不必改也不会失配**。

**D3（为什么不重编号、不改那 47 处引用）**：本仓的节级引用**只有两种形态**（`§6.6` 编号锚 · `§完整清单` 命名锚），
而引用门 ⑥ **只认 `文件:行号`** ⇒ **节级引用今天没有任何门**（实测：带文件名的 47 处 / 10 个文件；
`references.md` 文件内 `§+数字` 123 处 · `MATERIALS.md` 56 处 · 命名锚 115 处）。
**一次无门的重排 = 一场静默腐烂** ⇒ 本次用「保留标题 + 转发占位」把**老锚**当**冻结映射表**用，
把「补门」从**前置条件**降为**下一步**（见 Non-goals ①）。

**D4（清单口径四件）**：一份清单要可复核，必须同时给出 **① 集合定义 · ② 枚举根 · ③ 排除表 · ④ 枚举时刻**。
判据 = 「根 + 排除」：实测只给根 `G:\project\dsh1`、不给排除 ⇒ **14 行**，其中 **6 项不是材料**
（`.docs` · `.shadow` · `bin` · `node_modules` · `scripts` · `vendor`）。

**D5（状态标注由复核产生）**：§1 **升为当前态**（附 2026-10-07 复核块：8/8 + HEAD 逐项一致 + 复核命令）；
§1.1 **降为历史快照**（根已死、**永久**不可复核），按「可追溯性优先于清理」**保留原文不删、只加更正注**。

**D6（根与排除表收一处）**：新增 `tools/materials-root.lib.ts` —— `materials-ledger.ts` 与 `materials-freshness.ts`
共用同一份 `requireMaterialsRoot` / `isMaterialDir` / `exclusionLine`；**删掉两个工具里写死的默认根**（缺件即拒，ADR-0049）。
同族的「一个判据只能有一份实现」先例：`tools/comparison-points.lib.ts`、`core/util.ts:numOr`。

**D7（生成器不许手写派生计数）**：`materials-ledger.ts` 尾部那句硬编码「24/24」改为**实算**。

## Consequences

| 面 | 得到什么 | 代价（如实记） |
|---|---|---|
| 归属 | 两个文件各自只答一个问题；**新增内容有明确落点**（清单 → `MATERIALS.md`；核实 → `references.md`） | 两个文件头各多一段归属声明 |
| 可复核 | 清单有了**四件口径**与**一条命令**；§1 的 8 项可逐项复核 | §1 的「身份」列仍**不可机械推**，要人核 |
| 引用 | **47 处节级引用一处未改、一处未破** | 两个小节变**空壳 + 转发占位**（可读性下降，换来不失配） |
| 工具 | 死根消除；两个工具的根与排除表**只有一份实现**；计数实算 | 两个工具**多了一个 import**；无参运行从「静默用死根」变成 **exit 2**（行为变更） |
| 状态标注 | 「当前态」这个词**改由复核产生** | §1.1 的 24 行**仍是不可复核的表**（刻意保留） |

## Non-goals（**本次刻意不做**）

1. **不做目录化**（`references.md` → `references/` 拆成 ~20 份）：它与「改 47 处 + 123 处自引」绑定，
   且**必须先有节级引用门**。列入 `BACKLOG` `T28`。
2. **不重编号、不改任何节级引用** —— 理由见 D3。老锚即映射表。
3. **不立节级引用门**：本次**不破锚**，前置条件不存在；要做时**必须同时支持编号锚与命名锚**
   （只认 `§N` 会漏掉 115 处命名锚），否则是「门绿着、判别力没有」。
4. **不动 `adr/0089` 正文**（**已接受** ⇒ 归档层，只写补记）与其 5 处引用。
5. **不改 `MATERIALS.md` §1.1 的 24 行数字**（归档层改写＝伪造历史）。

## 判据与可复核命令

```powershell
$node = "$env:LOCALAPPDATA\mise\installs\node\26.10.0\node.exe"   # 本机 node 不在 pwsh PATH 上

# ① 迁移守恒：21 条 URL 只应出现在 MATERIALS.md（references.md 应为 0）
(Select-String -LiteralPath references.md -Pattern '^- https://github\.com/').Count   # 期望 0
(Select-String -LiteralPath MATERIALS.md -Pattern '^- https://github\.com/').Count    # 期望 21

# ② 标题守恒：迁移**不得**改动标题数（用「保留标题 + 转发占位」实现）
(Select-String -LiteralPath references.md -Pattern '^#{1,3} ').Count                  # 迁移前=61，期望仍 61

# ③ 转发占位在位
Select-String -LiteralPath references.md -Pattern '^## 完整清单|^### 14\. 材料面清单'

# ④ 工具：无默认根（两条都应 exit 2）· 排除表生效 · 计数实算
& $node tools/materials-ledger.ts                                   # exit 2
& $node tools/materials-freshness.ts                                # exit 2
& $node tools/materials-ledger.ts G:\project\dsh1 vendor\_upstream  # 口径行 + 「4/4」实算
```
